# links.ranimontagna.com

Astro static site for Ranielli Montagna's first-party personal links page.

## Commands

- `pnpm dev`
- `pnpm build`
- `pnpm preview`
- `pnpm check`
- `pnpm test`

## Deployment

Target production URL: `https://links.ranimontagna.com`.

Static output is generated with:

```bash
pnpm build
```

Local development runs at `http://localhost:4321` by default:

```bash
pnpm dev
```
